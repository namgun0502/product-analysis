# 03_video_product_analysis_plan.md

남건, '영상의 링크를 올리면 AI가 영상을 분석해서 영상 속 제품들을 분석해주는 앱'의 전체 구현 계획서입니다.

---

## 1. 프로젝트 개요 및 목표
- **목표**: 사용자가 유튜브(YouTube), 릴스, 쇼츠 등의 영상 링크(또는 영상 파일)를 입력하면, AI가 영상을 시각적/맥락적으로 분석하여 **영상에 등장하는 제품 목록, 등장 시간(타임스탬프), 카테고리, 제품 설명 및 쇼핑 검색 연동 정보**를 깔끔한 카드 형태로 추출해주는 웹 애플리케이션 개발.
- **핵심 가치**: 
  - "이 영상에서 입은 옷이 뭐지?", "이 브이로그에 나온 조명/인테리어 소품은 어디 제품이지?"와 같은 궁금증을 단 몇 초 만에 해결.

---

## 2. 주요 기능 정의

### ① 영상 링크 입력 및 미리보기
- YouTube, Shorts 등 영상 URL 입력창 제공.
- 입력된 링크를 바탕으로 영상 썸네일 또는 임베드 플레이어 즉시 로드.

### ② AI 멀티모달 영상/제품 정밀 분석 (Gemini AI 연동)
- 영상의 프레임 및 메타데이터를 기반으로 제품 인식:
  1. **제품명 및 추정 브랜드/모델명**
  2. **카테고리** (패션/의류, 전자기기, 뷰티/화장품, 가구/인테리어, 주방용품, 악세서리 등)
  3. **등장 시간대 (타임스탬프)** (예: 00:15, 01:23)
  4. **제품 외형 및 특징 설명** (색상, 소재, 디자인 포인트)
  5. **쇼핑 검색 바로가기 키워드** (네이버 쇼핑, 쿠팡, 구글 쇼핑 연계 버튼)

### ③ 타임라인 기반 제품 하이라이트 UI
- 영상 재생 시 해당 구간에 나오는 제품이 실시간으로 하이라이트되는 인터랙티브 뷰.
- 제품 카드 클릭 시 해당 타임스탬프로 즉시 점프 재생.

### ④ 분석 결과 저장 및 내보내기
- 분석한 제품 리스트를 클립보드 복사, 엑셀/텍스트 다운로드, 공유 기능.

---

## 3. 기술 스택 및 아키텍처

- **프레임워크**: Next.js 15 (App Router, TypeScript)
- **스타일링**: 모던 디자인 시스템(Dark/Light 테마 지원, 미려한 유리 모피즘 및 카드 레이아웃)
- **AI 엔진**: Google Gemini 1.5 Flash / Pro (비디오 및 이미지 멀티모달 분석, JSON 구조화 출력)
- **배포 환경**: Cloudflare Pages / OpenNext (기존 설정 활용)

---

## 4. 단계별 진행 순서 (Step-by-Step)

1. **[1단계] UI 뼈대 및 디자인 시스템 구축**:
   - 영상 링크 입력창, 분석 시작 버튼, 로딩 애니메이션.
   - 분석 결과 대시보드 (영상 플레이어 영역 + 제품 카드 그리드 영역).
2. **[2단계] AI 분석 API 연동 (Gemini API)**:
   - Next.js API Route (`/api/analyze-video`) 구현.
   - 영상 링크 및 메타데이터를 기반으로 구조화된 JSON 데이터(제품명, 타임스탬프, 카테고리 등) 추출 프롬프트 작성.
   - API 키 보안 설정 (`.env.local`).
3. **[3단계] 타임스탬프 연동 및 쇼핑 검색 링크 생성**:
   - 타임스탬프 클릭 시 유튜브 플레이어 제어 (시간 이동).
   - 네이버/쿠팡/구글 쇼핑 바로가기 링크 자동 생성.
4. **[4단계] 테스트 및 최종 검증**:
   - 실제 다양한 영상 링크(패션 룩북, 데스크 셋업, 브이로그 등)를 테스트하여 정확도 확인.
