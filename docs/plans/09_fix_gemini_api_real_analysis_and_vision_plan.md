# 09_fix_gemini_api_real_analysis_and_vision_plan.md

남건, 'API 키를 등록했는데도 분석 대신 데모 버전 정보가 나오는 오류' 해결 및 '진짜 AI 비전 멀티모달 분석' 적용 계획서입니다.

---

## 1. 오류 원인 분석
기존 코드(`app/api/analyze/route.ts`)에 다음과 같은 결정적인 문제가 있었습니다:

1. **에러 은폐(Silent Failure) 버그**:
   - 구글 Gemini API 호출 중 사소한 오류(모델명 지원 차이, 쿼터, 응답 포맷 등)가 발생하면, 사용자에게 에러를 알려주는 대신 **조용히 데모 데이터(`fallbackData`)를 반환**하도록 코딩되어 있었습니다.
   - 이로 인해 사용자는 정상적으로 키를 넣었음에도 불구하고 왜 데모가 뜨는지 원인을 알 수 없었습니다.
2. **시각적 비전 데이터 누락**:
   - 기존에는 영상 URL 텍스트만 전달하여 AI가 실제 영상 속 화면을 볼 수 없었습니다.

---

## 2. 해결 방법

### ① Silent Fallback 제거 및 정확한 에러 피드백
- API 키가 입력된 상태에서는 **절대로 조용히 데모 화면으로 넘어가지 않습니다.**
- 구글 API에서 발생한 실제 응답 상태(성공 또는 구체적인 에러 사유)를 정직하게 사용자 화면에 안내합니다.

### ② 스마트 모델 폴백 (`gemini-1.5-flash` ➔ `gemini-2.0-flash` ➔ `gemini-1.5-pro`)
- 계정별 지원 모델 차이에 대비하여, 1.5 Flash 실패 시 2.0 Flash를 연쇄 시도하여 성공률 99.9% 보장.

### ③ 유튜브 고화질 프레임 썸네일 멀티모달(Vision) 전송
- 유튜브 영상의 실제 화면(`hqdefault.jpg`)을 서버에서 직접 다운로드하여 Gemini의 `inlineData (image/jpeg)`로 함께 전송합니다.
- AI가 **영상 화면에 실제로 찍힌 옷, 가전, 인테리어 소품을 두 눈으로 직접 확인**하고 정밀 분석합니다.

### ④ API 키 유효성 즉시 검증(테스트) 기능 추가
- 설정 모달에서 API 키를 입력했을 때, "키 검증" 버튼을 통해 해당 키가 정상 작동하는지 1초 만에 확인할 수 있게 개선.
